# Changelog

All notable changes to this project are documented in this file.

## [0.9.2] - 2026-09-08

### Changed
- Dependency update.
Relaxed the `numpy<2.0.0` upper bound, which bumps minimum version dependencies of `torch` (`>=2.3.1`) and 
`torchvision` (`>=0.18.1`).

## [0.9.1] - 2026-04-09

### Changed
- URL update for models due to hosting change from Netlify to S3.

## [0.9.0] - 2025-10-01

### Added
